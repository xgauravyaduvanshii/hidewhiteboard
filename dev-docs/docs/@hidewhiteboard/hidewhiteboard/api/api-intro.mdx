# API

Currently the **API** is divided into 3 broad categories 👇

- [Props](/docs/@hidewhiteboard/hidewhiteboard/api/props) - The `props` you can pass to the `hidewhiteboard` component.
- [Children components](/docs/@hidewhiteboard/hidewhiteboard/api/children-components) - Official components you can use to customize the UI.
- [Utils](/docs/@hidewhiteboard/hidewhiteboard/api/utils) - Utilities and helpers you can use to export, restore and more.
