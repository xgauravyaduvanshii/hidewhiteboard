## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup and introduction.
- [@hidewhiteboard/hidewhiteboard](/docs/@hidewhiteboard/hidewhiteboard/installation) — docs for the npm package to help you integrate hidewhiteboard into your own app.
- Editor — IN PROGRESS. Docs describing the internals of the hidewhiteboard editor to help in contributing to the codebase.
- [@hidewhiteboard/mermaid-to-hidewhiteboard](/docs/@hidewhiteboard/mermaid-to-hidewhiteboard/installation) - Docs for the mermaid to hidewhiteboard parser
